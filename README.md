# Hotel System Project

A C++ Hotel Management System designed to manage hotel rooms, customers, reservations, and basic hotel operations.

## Features

- Manage hotel rooms
- Add and manage customers
- Make room reservations
- Check room availability
- Manage check-in and check-out
- Display hotel and reservation information

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Data Structures
- Standard Template Library (STL)

## Project Structure

The project is organized into different classes and components to handle rooms, customers, reservations, and hotel management operations.

## How to Run

1. Clone the repository.
2. Open the project in Visual Studio.
3. Build the project.
4. Run the application.
